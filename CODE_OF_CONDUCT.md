# Code of Conduct – AIDE

## Our Pledge

We are committed to creating a **respectful, inclusive, and supportive** environment for everyone working on AIDE.

This project is built by a team of junior developers, so learning and collaboration are core values.

---

## Expected Behavior

- Be respectful and kind to others
- Be patient when reviewing or explaining code
- Ask questions when something is unclear
- Give constructive and helpful feedback
- Accept feedback with an open mindset

---

## Unacceptable Behavior

- Harassment, discrimination, or offensive language
- Toxic or aggressive communication
- Dismissing questions or belittling others
- Repeatedly ignoring project guidelines

---

## Our Goal

AIDE exists to help **caregivers and cared people**.  
We work better when we **support each other**.

Thank you for helping make this a safe and productive space 💙
